open-blueprint

Zero-runtime-overhead CLI utility that scaffolds and verifies governance structures for agentic AI tools.

v1.0.0 MIT Node ≥20 Bun ≥1.0 LSP

Purpose

bp takes a repository, detects its topology, and scaffolds a standardized governance structure suitable for any of 31+ agentic AI backends (Claude, Cursor, Cursor, Gemini, etc.). It then runs a 4-layer validation pipeline and can translate between platforms.

Core Components

🔌
Detector

Scans the project and builds a Fingerprint — a snapshot of languages, frameworks, tooling, security signals, directory topology, entry points, and Git workflow. Also enriches the fingerprint with a risk tier and suggested agent approval mode.

Entry: src/detector/index.ts

🪜
Templater

Reads .hbs templates per backend and renders them using the fingerprint as context. Supports risk-based template selection, blueprint inheritance, and conditional generation (skip templates that do not match the project's profile).

Entry: src/templater/index.ts

✅
Validator

Runs a 4-layer (plus governance) validation gate on all governed files. Layers: Structural (file integrity, frontmatter, encoding), Semantic (rule consistency, cross-references), Logical (contradictions, cycles), Drift (fingerprint delta). Includes caching, resource limits, and a 30 s timeout.

Entry: src/validator/index.ts

🌍
Translator

Parses a backend-specific blueprint into a canonical BlueprintIR and renders it back to any other backend. Each of the 31+ backends has a dedicated adapter implementing BlueprintAdapter.

Entry: src/translator/index.ts

⚙
Config

Manages per-project configuration via .bp.json. Schema defines backends, primary backend, inheritance (extends), plugins, overrides, and workspace scanning options.

Entry: src/config/project.ts

🔒
Security

HMAC-signed audit logging, governance hook validation, path-traversal guards, and a plugin sandbox based on node:vm. All registry fetches enforce HTTPS.

Entry: src/security/

🛠
Plugins

Loads custom validator plugins in an isolated VM with a restricted API. Plugins can call validate(), log(), and error() to inject findings into the validation result stream.

Entry: src/plugins/loader.ts

🗃
Registry Client

Fetches and installs template packs from a registry. Supports offline fallback and signature verification (RSA). Mock registry for unit testing. Entry into the template marketplace.

Entry: src/registry/client.ts

📊
Telemetry

OpenTelemetry-compatible tracing with auto-injected correlation IDs. Disabled in tests. Structured logging via Pino with redaction of secrets, tokens, and keys. SARIF output for CI integration.

Entry: src/telemetry/

🔃
Blueprint Sync

Diff, merge, and drift-reconciliation routines. Compares local fingerprints against the canonical state and suggests or auto-applies fixes.

Entry: src/blueprint-sync/

🔬
LSP Server

Language Server Protocol implementation for real-time blueprint validation. Provides diagnostics, completions (triggered on :, -, and space), document hover, and code actions.

Entry: src/lsp/server.ts

🧮
Enterprise

Compliance reporting, runbooks, and environment-template scaffolding for regulated teams.

Entry: src/enterprise/

Validation Pipeline

LayerWhat it checksWhen skipped
1. StructuralFile existence, frontmatter, encoding, size, BOM, unclosed code fencesNever
2. SemanticRule consistency, cross-references, duplicate commands, invalid scopes, MCP completenessStructural hard failures
3. LogicalRule contradictions, circular skill dependencies, semantic contradictionsStructural hard failures
4. DriftFingerprint delta, entry-point drift, test command drift, dependency driftOnly when level≠drift|all
5. GovernanceSettings, commands, identity, audit, compliance, risk, registry, orchestration, RBAC, cross-layer refs, cost, alertingExplicit flag only

Caches per-file validation results keyed by content hash. Timeouts after BP_VALIDATION_TIMEOUT_MS (default 30 s).

Key Data Models

Fingerprint

Generated by the Detector. Captures: project name, type, Git workflow, detected languages, frameworks, tools, entry points, directory topology, and security signals.

BlueprintIR

Canonical intermediate representation. Every backend adapter parses its native format into this uniform structure — rules, skills, agents, hooks, settings, commands, identity, audit, compliance, risk, registry, cost, alerting, MCP servers, and orchestration.

BackendManifest

Tells the CLI which file patterns to look for, max file sizes, and the frontmatter schema expected for each section (rules, skills, agents).

Security & Observability

📜
Audit Logger

HMAC-SHA256 signed log entries written to ~/.bp/audit-YYYY-MM-DD.log. Includes command, args, user, correlation ID, and status. Symlink ~/.bp/audit.log always points to the active day.

🔶
Tracing

OpenTelemetry spans for every major phase (bp.detect, bp.validate, etc.). Errors are recorded as span exceptions. Pino logs are redacted for apiKey, token, secret, password, and privateKey.

🔒
Sandbox

Plugin scripts run in a Node.js VM with no access to require, process, or console — only the provided PluginAPI wrapper. Template vars are sanitized against shell metacharacters and prototype pollution.
